# AYRA — Made for every day

Premium reusable bottle landing page built with:

- React
- Vite
- Tailwind CSS v4
- JavaScript

## Features

- Responsive landing page
- Interactive bottle color selector
- Bottle size selector
- Product navigation
- Scroll-aware navigation
- Marketplace section
- Responsive layout
- Modern lifestyle-focused UI

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
